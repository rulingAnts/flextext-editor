Flextext Recovery

Finds the texts the Flextext apps keep inside the browser and saves each one exactly as the app's own Save would: the .flextext, and when the app would zip it, the recording and the other files that ride with it. Nothing is sent anywhere; this page works with no internet.

1. Find the browser's profile folder

On the computer that has the texts, the browser keeps them in its profile folder:

  • Windows, Chrome: %LOCALAPPDATA%\Google\Chrome\User Data\Default  (Edge: %LOCALAPPDATA%\Microsoft\Edge\User Data\Default)
  • macOS, Chrome: ~/Library/Application Support/Google/Chrome/Default
  • Linux, Chrome: ~/.config/google-chrome/Default  (Chromium: ~/.config/chromium/Default)

A second browser profile is named Profile 1, Profile 2… instead of Default. The address bar page chrome://version shows the exact path as "Profile Path".

Inside it, the two folders that matter are IndexedDB (the texts and recordings) and Local Storage (the device settings). Choosing the whole profile folder works. To move them on a thumb drive, copy just those two into one folder and choose that folder. Copying is most reliable with the browser closed.

2. Choose that folder

or drop the folder here. The browser may ask whether to let this page read the files: it only reads them.

Flextext Recovery, built with the Flextext engine __ENGINE_VERSION__. Files it saves say so in their exportSource.
