Fix tabs in a .flextext file

Perbaiki tab dalam file .flextext

Choose one or more .flextext files. This page finds TAB characters inside the text — in the baseline, the words, glosses and translations — and makes a fixed copy for you to download. FLEx reads a tab as part of the text, which is what goes wrong. Your original file is not changed, and nothing leaves this computer: the page works without the internet.

Pilih satu atau beberapa file .flextext. Halaman ini mencari karakter TAB di dalam teks — di baris dasar, kata, glos dan terjemahan — lalu membuat salinan yang sudah diperbaiki untuk diunduh. File asli tidak diubah, dan tidak ada yang dikirim ke mana pun: halaman ini bekerja tanpa internet.

What exactly is changed · Apa yang diubah

Inside the text of an element, a run of spaces that holds a tab becomes one space between words, and is removed at the start or end. Text with no tab in it is not touched, and neither is anything outside the text: tags, attributes, the layout between lines and every other character stay exactly as they were. Before you are offered the download, the fixed copy is read back and checked: it must be well-formed, have exactly as many texts, paragraphs, phrases, words and other elements as the original, and contain no tab in any text.

This is the same rule the FlexText apps apply when they export, from version 725.
